# Pratik Sarode | Product portfolio

Product-focused portfolio for an AI Product Engineer profile (insurance claims and fraud/AML). Static site: plain HTML, CSS and a small amount of vanilla JS. No build step.

## Structure

- `index.html`: content (approach, two case studies, experience, toolkit, contact)
- `styles.css`: design tokens and layout (Editorial Dark base, amber accent)
- `main.js`: case study tabs, toolkit filter, mobile nav
- `assets/`: photo and certification images
- `Resume/`: current product-focused CV

## Run locally

Open `index.html` in a browser, or serve the folder with `python3 -m http.server`.

## Deploy

GitHub Pages from the `main` branch, root folder.
